# chat BOT v6.0.0

بوت WhatsApp محلي بواجهة عربية، جلسات مستقلة، إرسال مُجدول وفوري، مجموعات، تفاعل حتمي، أتمتة بالتاريخ، وخلفيات متحركة قابلة للتخصيص. لا توجد خدمة AI خارجية داخل المساعد المحلي.

## أهم ما في v6

- دورة صور حقيقية: لا تتكرر الصورة داخل الدورة، وبعد اكتمال جميع الصور لكل الأهداف تبدأ دورة جديدة تلقائيًا.
- حالة لكل مرحلة: رسالة قبل الصورة، الصورة، ورسالة بعدها، مع مفاتيح تحقق تمنع اعتماد حالة قديمة عند تغيير النص أو الملف.
- حماية تكرار اختيارية في الإرسال الفوري، مع خيار احتساب الإرسال الفوري ضمن دورة الصور.
- ترتيب تنفيذ مستلم-أولًا أو صورة-أولًا.
- إرسال للمستلمين والمجموعات مع فحص مسبق وعزل فشل كل هدف.
- تفاعل تلقائي: رسائل وReaction، أولوية للقواعد، cooldown، rate limit، ساعات هدوء، نطاق عام محدد IDs، ونطاق خاص لكل قاعدة.
- إدارة المجموعات: اكتشاف، تحليل GID، تحليل دعوة، تحديث، اختبار، وتعطيل/تمكين.
- تسع خلفيات متحركة. لكل نمط ملف إعدادات مستقل.
- المطر الرقمي أصبح نمط شاشة هاكر/CRT قابلًا لتغيير اللون، Glow، Trail، الحجم، الأحرف، التشويش، scanlines، ورأس العمود.
- السديم والنيزك يدعمان تفاعل المؤشر والنقر والنبضات/الصدمة.
- الصور الجديدة تُرتب باسم `img.1.ext`, `img.2.ext`… مع الحفاظ على التوافق مع الأسماء القديمة.
- البيانات محلية داخل `data/sessions/<session>`، وربط WhatsApp مستقل لكل جلسة.
- الواجهة لا تستخدم polling تلقائي؛ التحديث من المستخدم أو بعد الإجراء.

## التشغيل

```bash
npm install --no-audit --no-fund
npm run verify
npm start
```

أو استخدم `run.py` في Windows وفق إعدادات المشروع. المنصة تحتاج Node.js 20 أو أحدث ومتصفح Chrome/Edge متوافق.

## ملاحظة WhatsApp

الإرسال الفعلي يعتمد على WhatsApp Web ونسخة `whatsapp-web.js` المثبتة في `package.json`. توجد طبقة توافق محلية في `scripts/patch-whatsapp.js`، ولا تُعد اختبارات Node بديلًا عن اختبار حساب WhatsApp حقيقي.
