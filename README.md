# chat BOT v6.5.2 — Classic Original Style

نسخة تطور الأنظمة الداخلية مع الحفاظ على شكل التحكم الأول وبساطة الاستخدام.

## التشغيل

```bash
npm install --no-audit --no-fund
npm run verify
npm start
```

على Windows يمكن استخدام `python run.py`. المنفذ الافتراضي `7005`.

## الأنظمة

- جلسات WhatsApp مستقلة فعليًا، ولكل جلسة أرقام ومجموعات ووسائط وإعدادات وربط مستقل.
- أرقام دولية مع اختيار الدولة وفحص الرقم قبل الحفظ.
- اكتشاف المجموعات من WhatsApp، وتحليل GID، وحفظ المجموعة داخل الجلسة الحالية فقط.
- إرسال النص والصور والملفات مع اختيار ترتيب الإرسال، حماية تكرار، إعادة محاولة، وعزل فشل كل هدف.
- جدولة أسبوعية/مرة واحدة تعمل من الخادم، مع دعم المجموعات حسب إعداد الجلسة.
- تفاعل تلقائي للرسائل وReaction مع قواعد، نطاقات، تهدئة، وحدود أفعال.
- خلفيات متحركة محلية قابلة للتخصيص، مع خلفية خاصة لكل جلسة.

لا توجد خدمة AI خارجية في المشروع. لا ترفع مجلد `data/` أو ملفات المصادقة إلى GitHub.
